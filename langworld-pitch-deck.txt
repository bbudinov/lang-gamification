============================================================
SLIDE 1: Title
============================================================

LangWorld
Learn languages by living in them.

A game world where kids practice speaking, listening, reading
and writing in a new language — through immersive scenarios, not textbooks.

============================================================
SLIDE 2: The Problem
============================================================

Language apps today teach words. Not language.

- Kids memorize "apple = ябълка" but can't say "Can I have an apple?"
- Most apps are multiple choice quizzes — no speaking, no listening, no real practice
- The #1 complaint worldwide: "I understand but I'm afraid to speak"
- Age 7–14 is almost completely ignored — apps are either for toddlers or adults

There's no product that makes kids actually PRACTICE using a language
in real, meaningful scenarios.

============================================================
SLIDE 3: The Solution
============================================================

LangWorld is an interactive language world with 9 exercise types
that train every language skill:

LISTENING
  - Listen & Repeat — hear a phrase, say it back, get scored
  - Word Quiz — hear a word, pick the correct translation

SPEAKING & PRONUNCIATION
  - Say It! — pronounce words, get syllable-by-syllable feedback
    (Fluently-style: each syllable scored, visual breakdown, tips)
  - NPC Talk — have a real AI conversation with a 3D talking avatar

READING
  - Fill the Scene — read a sentence, pick the missing word
  - True or False — read a word-translation pair, judge if correct

WRITING / SPELLING
  - Word Scramble — arrange letters to spell the word
  - Memory Match — find matching word pairs
  - Memory Mix — cross-topic card matching challenge

Every skill. Every session. Through play.

============================================================
SLIDE 4: How It Works
============================================================

1. Open the app → optimized 3D city map with 12 themed locations
2. Tap a location (Zoo, Restaurant, Hospital, Bank...)
3. Pick a game type → play 5-8 rounds
4. Earn XP → unlock new locations
5. 3 levels per location: Discover → Use → Survive
6. Professor Globe — a 3D talking avatar — guides you with
   real-time lip-synced speech, expressions, and conversation

No accounts required. No setup. Just play.
(Optional: kid-friendly PIN login for cloud sync)

============================================================
SLIDE 5: 3D Talking Avatar — The AI Teacher
============================================================

Professor Globe is a full 3D character with:
- Real-time lip sync matched to speech output
- Eye blinking and natural idle animations
- Head tracking (follows the camera)
- Zoom-in effect when speaking
- AI-powered conversations (Claude API) — not scripted
- Never punishes mistakes — always encourages and explains
- Encyclopedia mode: ask about ANYTHING and get a real answer

Built with React Three Fiber + Rhubarb Lip Sync.
168 pre-generated lip sync data files for word-level accuracy.
Realtime audio-based lip sync for AI conversation responses.

This is not a chatbot. This is a character you talk to.

SLIDE 8: The NPC Talk Experience
============================================================

This is our key differentiator.

Child taps microphone → speaks freely (unlimited time) →
presses "Done" → AI responds with contextual, in-character dialogue →
3D avatar speaks with lip sync → child responds again.

What makes it special:
- Avatar is a REAL 3D character, not a flat chatbot
- Conversations are contextual (at the zoo, restaurant, hospital)
- AI corrects mistakes naturally ("Oh, you mean THE CAT? Great!")
- NPC remembers previous conversations
- Child can ask about ANYTHING — AI has encyclopedia knowledge
- Fuzzy matching fixes speech recognition errors (bigs → pigs)
- All in the target language — full immersion

============================================================
SLIDE 9: Tech Stack
============================================================

Frontend:  Next.js 16 + React 19 + TypeScript
3D World:  Three.js + React Three Fiber (optimized: InstancedMesh, 1K draw calls)
Avatar:    3D GLB model + Rhubarb Lip Sync + WebAudio analyser
Styling:   Tailwind CSS v4
State:     Zustand (offline-first, syncs to Supabase)
AI:        Claude API (Anthropic) — NPC conversations
Audio:     Google Cloud TTS (pre-generated MP3s)
Speech:    Web Speech API (browser-native, free)
Auth:      Supabase (email + kid PIN login)
Deploy:    Vercel (serverless)
PWA:       Service Worker + Web App Manifest

Zero backend infrastructure needed.
Everything runs client-side except AI conversations.

SLIDE 12: Key Differentiators
============================================================

vs Duolingo:
  - Duolingo = multiple choice quiz app, gamified drill
  - LangWorld = immersive world with AI conversations + 9 exercise types
  - Duolingo has NO real speaking practice
  - LangWorld has syllable-level pronunciation feedback + free-form AI chat

vs Lingokids / Khan Academy Kids:
  - Those are for ages 3–6 (preschool)
  - LangWorld targets 7–14 (underserved market)

vs ChatGPT / AI tutors:
  - Those are chat interfaces, not games
  - Kids don't want to "chat with AI" — they want to PLAY
  - No pronunciation feedback, no game mechanics, no motivation loop

vs Praktika.ai:
  - Praktika = adult-focused, subscription-heavy
  - LangWorld = kid-first, game-first, scenario-based
  - Both have 3D avatars, but LangWorld adds game world + exercises

LangWorld combines:
  3D game world + Real exercises + AI avatar conversations +
  Pronunciation feedback + Encyclopedia knowledge
  ...in one product, for an underserved age group.
